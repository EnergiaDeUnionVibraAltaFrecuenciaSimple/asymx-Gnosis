asymx-Gnosis: Arquitectura de Navegación Bio-Mecánica
Este repositorio es una extensión técnica del asymx-framework. Mientras que el framework base establece la estructura de visibilidad y el "Punto X", asymx-Gnosis implementa los motores de filtrado y detección de frecuencia necesarios para navegar la "Mecánica de la Universa".
🛠 Motores de Precisión (Filtros de Frecuencia)
Se ha realizado una poda radical de la narrativa para extraer exclusivamente la geometría funcional del sistema:
1.	Procesador Gnóstico (procesador_gnostico.py): Utiliza la lógica de la Unidad para validar la coherencia de los datos. Si un impulso genera dualidad o ruido, el sistema lo descarta por ineficiencia.
2.	Optimizador Micelial (red_micelial.py): Algoritmo de ruta mínima basado en redes biológicas. Selecciona el camino de menor resistencia para la transmisión de información.
3.	Resonancia Elemental (resonancia_elemental.py): Analizador de conductividad atómica. Clasifica la información por familias (Nobles, Transición, Sintéticos) y detecta estructuras invisibles (Materia Oscura).
4.	Geometría Sagrada (geometria_sagrada.py): El juez final de calidad.
• Proporción Áurea (\phi 1.618): Validación de patrones orgánicos.
• Vesica Piscis: Cálculo matemático de la intersección "X".
• Entropía Positiva: Tolerancia adaptativa (15%) para el crecimiento asimétrico natural.
📐 Principios de Diseño
• Fractalidad: Validación de autosemejanza en todas las escalas de datos.
• Ciclos Ancestrales: Integración de frecuencias temporales (Ciclo de Venus/Mayas) para predicción de patrones.
• Eficiencia Nivel 1: Código ligero, local y orientado a la identificación de lo invisible.
